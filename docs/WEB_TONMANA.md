# Webのトンマナ（株主ポータル）

2026年10月5日、利用者の決定により、Webも日本信達のトンマナ標準 v01.01 に従うことになった。
正本はスキル `shintatsu-masp047-v01-01` である。実装の正本は `assets/style.css` の冒頭である。
以前のコーポレートサイト準拠（赤 `#AA2924` の塗り、黒のヘッダー）は廃止した。

## 1　色

| 用途 | HEX |
| :--- | :--- |
| 地 | `#FBFAF7` |
| 本文 | `#161820` |
| 見出し、表の見出し行の文字、ボタンの塗り | `#1C2951`（信達紺） |
| 線・点・数字（現在地の下線、ラベル、カードの上辺） | `#b04123`（SHINTATSU RED） |
| 補足の文字 | `#4A4F5A` |
| 罫線 | `#B7BFC4` |

赤は面（ベタ塗り）に使わない。表の見出し行は塗らず、紺の文字と紺の下罫で示す。

## 2　書体

| 用途 | 書体 |
| :--- | :--- |
| 見出し、ナビ | Zen Old Mincho（太字700） |
| 本文、節見出し（h3） | Noto Sans JP |
| 欧文・数字、英字ラベル | Inter |

Google Fonts から Zen Old Mincho、Noto Sans JP、Inter を読み込む。

## 3　大きさ

標準の文字サイズ体系は文書・スライド向けで、Web の規定がない。
決まるまで、従来の値を仮に使う。

| 要素 | PC | スマホ（640px以下） |
| :--- | :--- | :--- |
| 本文 | 18px、行間1.75 | 16px |
| h1 | 40px | 28px |
| h2 | 28px | 22px |
| h3 | 20px | 18px |
| 注記 | 14px | 14px |

## 4　形

- 白基調・細罫・余白。ヘッダーとフッターは地の色に細罫で区切る。
- 英字ラベルは赤の文字、字間0.3em、赤の細い下線。
- カードは細罫の枠と、上辺に2pxの赤線。数字は紺。
- 角丸、影、グラデーション、斜体は使わない。枠線は2px以下。
